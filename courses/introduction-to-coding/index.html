What you will learn

Understand the foundations.

This is not a promise to make you an expert in one week. It is a practical introduction designed to help you understand the field, try real code, and know exactly where to continue.

01

What coding means

Learn what programmers do and the kinds of websites, apps, and systems they create.

02

How websites work

Understand browsers, frontend, backend, databases, domains, and hosting in simple terms.

03

Developer pathways

Explore frontend, backend, mobile development, UI/UX, data, and other technology paths.

04

Developer tools

Get introduced to code editors, browsers, files, folders, and the basic tools used by developers.

05

HTML foundations

Write the basic structure and content of your own simple webpage.

06

CSS foundations

Add colours, fonts, spacing, and simple styling to improve your page.
